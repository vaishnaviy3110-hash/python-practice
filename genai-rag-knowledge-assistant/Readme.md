# GenAI RAG Knowledge Assistant

A domain-specific Generative AI knowledge assistant built using Python and Retrieval-Augmented Generation (RAG).

## Project Overview

This project demonstrates how a RAG system retrieves relevant information from a local knowledge base and prepares context for an AI-generated response.

## Features

- Document loading and text cleaning
- Text chunking
- Local text embeddings
- Semantic search
- ChromaDB vector database
- RAG context retrieval
- Prompt engineering
- Source tracking

## Technologies Used

- Python
- Sentence Transformers
- ChromaDB
- Generative AI / RAG
- Prompt Engineering

## Knowledge Base

The current knowledge base contains information about:

- Retrieval-Augmented Generation (RAG)
- Prompt Engineering
- FastAPI Basics
